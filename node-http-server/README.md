# Node HTTP Server

This project sets up a simple HTTP server using Node.js to serve a static HTML page.

## Project Structure

```
node-http-server
├── public
│   └── hello.html       # The HTML file served by the server
├── src
│   └── server.js        # The Node.js server file
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Getting Started

To run the server, follow these steps:

1. **Clone the repository** (if applicable):
   ```
   git clone <repository-url>
   cd node-http-server
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Start the server**:
   ```
   npm start
   ```

4. **Access the application**:
   Open your web browser and navigate to `http://localhost:3000` to see the greeting message.

## Dependencies

This project uses the built-in `http` module of Node.js, so no additional dependencies are required.
